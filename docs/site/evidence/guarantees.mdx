## How it is tested

- **Unit tests**, in `tests/NCode.Buffers.Tests`, each named for the behavior it checks. The ledger links them.
- **Property tests**, written with FsCheck. They replay one fixed seed, `20261115,12345`, so every run checks the
  same generated cases: they widen what is checked, and they do not search anew on each run.
  <Proof source="PropertySeed" />
- **A coverage gate.** `./build/Test-Coverage.ps1` fails below 98% line or branch coverage, and CI runs it. Coverage
  says that a line ran, not that a test checked what the line did. <Proof source="CoverageMinimums" />
- **Warnings are errors**, with the .NET analyzers at their recommended level. <Proof source="WarningsAsErrors" />
- **Two ban lists.** The library's own code cannot call a lenient text encoding or rent from a pool without saying
  whether the buffer holds a secret: an analyzer rejects both. <Proof source="BannedEncoding" />
  <Proof source="BannedBuffers" />
- **The samples are tests.** Every C# sample on this site that compiles is a test: the site's own in
  `tests/NCode.Buffers.Site.Tests`, which sees only the public API, so they compile only as your code would, and the
  README's in `tests/NCode.Buffers.Tests`. Code shown as not compiling is marked so, with the compiler's error.
  <Proof source="SiteSamplesDecision" />

### What a test can see

A test cannot watch the collector decide not to move an array. It can ask which generation the collector reports for
it. An array on the pinned object heap reports the oldest generation from the moment it is allocated, and the tests
behind [R3](#not-moved) assert that.


A test of zeroing keeps a view of the memory, disposes the owner, and reads the view. The tests behind
[R1](#zeroed-on-dispose) do this for a rented buffer and for both lifetimes.

```cs snippet=SiteGuaranteesZeroedThroughAView title="How a test sees that memory was zeroed"
```

## What tests cannot prove

- **Timing.** No test measures how long a comparison takes. [R4](#fixed-time) rests on the calls the library makes to
  .NET's fixed-time comparison, one for each chunk of at most `int.MaxValue` bytes with every chunk compared, and on
  .NET's documented contract for it.
- **What the collector does in your process.** The tests assert where an array is allocated. They do not assert what
  a collection moved, because the collector decides that.
- **Your code.** A test of the library cannot see whether your code disposes what it rents, or copies what it holds.
  [Ownership](/concepts/ownership/) says who zeroes what, and [Ways to get it wrong](/reference/pitfalls/) lists the
  mistakes the library lets you make.

## Run it yourself

With the .NET SDK that the repository's `global.json` names:

```sh
git clone https://github.com/NCodeGroup/Buffers.git
cd Buffers
dotnet test
```

Then, in PowerShell 7, the coverage gate, which lists every line no test runs:

```powershell
./build/Test-Coverage.ps1
```

To test your own code the same way, see [Test that your code zeroes its secrets](/guides/test-zeroing/).
