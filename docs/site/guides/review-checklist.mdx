## Search the diff for

Each of these is a sign of a leak. Search the diff for the text, and read the guide in the last column for what to
write instead.

| Search for | Why | Guide |
| --- | --- | --- |
| `Encoding.UTF8`, `Encoding.ASCII`, `new UTF8Encoding(` | A lenient decoder replaces bad bytes with characters nobody sent. <LeakCard leak="L8" /> | [Reject malformed UTF-8 and ASCII](/guides/strict-decoding/) |
| `ArrayPool<byte>.Shared`, `MemoryPool<byte>.Shared` | The shared pools do not pin or zero what they hand out. <LeakCard leak="L3" /> | [Which buffer?](/start/which-buffer/) |
| `isSensitive: false` | The buffer comes from the shared pool, on a path that holds a secret. <LeakCard leak="L3" /> | [Which buffer?](/start/which-buffer/) |
| `.ToArray()` | The copy is on its own: nothing zeroes it. <LeakCard leak="L9" /> | [Work with an API that takes or returns byte[]](/guides/byte-array-apis/) |
| `ToString()`, `GetString(`, `Convert.ToBase64String(` | A string cannot be erased. <LeakCard leak="L5" /> | [Read a secret without leaving a string behind](/guides/read-a-secret-without-a-string/) |
| `==` or `SequenceEqual(` on a MAC or a key | The comparison stops at the first difference, and its time tells where that was. <LeakCard leak="L7" /> | [Verify a MAC without leaking timing](/guides/verify-a-mac/) |
| `new ArrayBufferWriter` | Each time it grows, the smaller array is dropped with part of the secret in it. <LeakCard leak="L4" /> | [Build a secret of unknown length, and read it as one span](/guides/secret-of-unknown-length/) |
| `Rent(` without `using` | An exception, or an early return, skips the cleanup. <LeakCard leak="L6" /> | [Ownership: who zeroes what, and when](/concepts/ownership/) |
| `Advance(span.Length)` | `GetSpan` returns all the free space, so the writer commits elements you never wrote. <Proof sample="SitePitfallAdvanceBySpanLength" /> | [Serialize into a buffer that must not grow](/guides/fixed-size-buffer/) |

A checklist finds the common leaks. It is not an audit.
