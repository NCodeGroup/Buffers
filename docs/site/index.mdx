## Install

```sh
dotnet add package NCode.Buffers
```

## A key that is zeroed after use

This example fills a key on the stack, computes an HMAC-SHA256 over a payload with it, and zeroes the key when the
`using` block ends.


The example is a test in the repository. It compiles and passes on every pull request, and this page includes it
from there.
